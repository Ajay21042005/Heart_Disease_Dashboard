❤️ Heart Disease Analysis Dashboard

📌 Project Overview
This project is an interactive Heart Disease Analysis Dashboard created using Microsoft Power BI.

The purpose of this project is to analyze heart disease patient data, survival status, age groups, diabetes, serum sodium levels, and gender-wise patient information.

The dashboard converts raw patient data into meaningful insights using Power BI, Power Query, DAX, KPI Cards, Charts, and Slicers.

🎯 Project Objective
The main objective of this project is to analyze heart disease data and answer important business questions such as:
What is the total number of alive patients?
What is the total number of deaths?
What percentage of patients are alive?
What is the average age of alive patients?
Which age group has more alive patients?
What is the average serum sodium level by age group?
How does diabetes vary across age groups?
How does the data differ between male and female patients?

The dataset was cleaned and transformed using Power Query.
The following steps were performed:
Checked column names
Removed duplicate records
Checked missing/null values
Corrected data types
Prepared columns for analysis
Applied the changes to Power BI

💡 Project Outcome
This project demonstrates how Power BI can be used to transform raw healthcare data into an interactive analytical dashboard.
It provides a clear view of patient outcomes and helps users understand patterns related to age, gender, diabetes, serum sodium, survival, and mortality.
